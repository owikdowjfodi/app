## 現有資料與實作限制

- 主要狀態在 localStorage；主網站沒有配套應用後端。
- 查字使用 Wiktionary、Datamuse、線上翻譯及 English Dictionary API 等資料來源；失敗時有快取／內建備援／規則拆解分支。首頁「完全取消內建字典」與實際保留離線備援的文案需釐清。
- 閱讀文件最多四份、單份前 80,000 個字元、原始上傳限制 25 MB；PDF 是文字抽取，未見 OCR。相同檔名會取代最近文件中的舊項目；超過文件數量上限會裁切保留清單。
- 閱讀文件不在同步及 JSON 備份所共用的 GSYNC_KEYS 內；每日測驗進度也不在該鍵清單內。快取及 AI 金鑰亦不在其中。
- 同步涵蓋單詞本、錯題、最近查詢、學習統計、字根已學標記、想法庫、口說紀錄、AI 單字歷史、常錯發音字；本機快照只包含其中六類關鍵資料，沒有口說紀錄。
- 口說合併最多保留最近 300 筆；AI 字串／物件清單合併最多 500 筆；最近查詢亦有長度上限。因此「只增不減合併」不代表所有種類都無限保留。
- Google OAuth 預設用戶端 ID 留空；目前畫面要求使用者自行取得並填入，才可啟用登入備份。
