# 學習流程使用說明 — 2.4

## 1. 由文章接住學

1. 開閱讀文件，貼上或選一篇文章，點句子內的單字。
2. 原有字卡繼續可查字、發音及收藏；新增按鈕可直接做原句填字、口說造句或五角度構思。
3. 頁頂會保留原句及已做步驟。「開啟口說／構思」只表示開過，並非已完成練習。
4. 在單詞本按「文章來源」，可選同一字在不同文章／段落的來源。
5. 按「返回原文這一段」回到來源段落；「收起學習流程」只收起目前流程，不刪除來源、單字及過往步驟。

原句填字不依賴另一個干擾字，只有一個收藏字亦可練。原有每日五題測驗保持獨立；收藏字小測驗及原句題重開後可接續。

## 2. 記住讀到哪裡

每段下方可標為重點或加筆記；筆記預填段落文字，亦可自行改寫。閱讀工具列集中列出重點及筆記，按段落編號跳回。重新開文件會沿用上次段落及段內位置；不同螢幕的實際像素位置會略有差異。

## 3. 保護五稜鏡構思

輸入後短暫停頓會自動保存，底部顯示保存狀態。「草稿匣」可以切換多份自動草稿；原「我的想法庫」仍是獨立手動保存。

可按「立即存版本」留下目前內容，或用「草稿版本」逐角度比較，再恢復舊版。恢復前會先保存目前內容；版本亦包含當時 AI 建議及評分。

按「匯出草稿」下載 JSON；日後可經單詞本的 JSON 備份匯入按鈕合併。來源句子和閱讀筆記可能包含文章片段，即使未選整份文件備份亦可能隨文字資料備份。錄音不在 JSON 備份內。

若顯示保存失敗，先匯出草稿或文字備份，再檢查裝置空間；不要用清除網站資料來更新版本。
