# v2.5 使用方式

## 錄音

口說練習 → 展開本機錄音工具 → 錄製並停止 → 保存到我的錄音。相同題目與模式自動分組。名稱可不同，例如首次／加入例子後重練；可填下一次重練重點。我的錄音 → 首次／最新對照，可交替回放。錄音不納入 Google／JSON 備份，需下載另外保存。

## 統計

今日學習頁下方查看七日各類練習、答對率、常錯主題、改善字與下一次練習建議。主題來自單詞本手動標籤；多標籤分別計算。改善定義為最後一次答錯後至少連續兩次答對，而且最近答對在七日內。翻卡自評同樣計入。新一筆答錯會重新列入待鞏固。保存錄音不重複計數。

## Google

單詞本 → 備份與資料管理 → 設定與故障排解。依次填入 Client ID、登入授權、完成首次同步。只有雲端讀回核對成功才更新同步時間。需要網站擁有人提供有效 Client ID 並完成 Google Cloud 設定。
